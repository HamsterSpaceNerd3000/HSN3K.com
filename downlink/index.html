Downlink

FEATURES

Multi-feed desktop streaming environment engineered to view multiple live streams or videos in a low latency and resource environment.

Version 0.4.0 CLOSED ALPHA • Executable Installer / Portable Zip • Windows 10/11
[!] NOTICE: CLOSED ALPHA

Downlink downloads are currently restricted. The application is operating in a closed testing phase and public builds are not yet available for direct download.

Key Capabilities

FEATURES

Designed specifically to bypass web browser overhead and manage high-bitrate live feeds during multi-angle launch coverages.

[01] Multi-Stream & Grid Playback

Play multiple streams simultaneously in resizable windows with automatic grid layout calculations.

[02] Universal Stream Resolution

Dynamic extraction of playable stream URLs, metadata, and thumbnails from raw RTSP/M3U8 streams and website links via yt-dlp.

[03] Native Embedded Media Players

Hardware-accelerated video rendering powered by libVLC alongside embedded WebView surfaces for native grid playback.

[04] Visual Feed & Output Management

Centralized dashboard to store, edit, group, and persist feeds and preset layout configurations in local storage.

[05] Drag-and-Drop Output Builder

Interactive workspace using visual ghost overlays to assign, swap, or reorder feeds across playback output slots.

[06] Auto Connection Recovery

Active playback monitoring with automatic stall and buffer detection and instant reconnection logic for dropped streams.

[07] Async Loading & Progress

Threaded stream extraction coupled with a non-blocking modal progress popup during multi-feed playback initialization.

[08] Diagnostic Debug Logging

Non-blocking, queue-backed debug logging system with custom timestamping enabled via environment variables.

[09] Discord Credit Linking

Link copying system that uses feed title and is formatted for easy use in a Discord environment.

[10] WebP/GIF Extraction

Extract a WebP, or a GIF, of the previous set of time (length of time can be customized) for any feed. Extracts to a set folder.

Developer & Source Build

SOURCE

If you prefer running Downlink from source on Linux or modifying the UI, you can clone the repository and run it directly in a Python environment.

# Clone repository
git clone https://github.com/HamsterSpaceNerd3000/downlink.git
cd downlink

# Set up virtual environment and run
uv venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
