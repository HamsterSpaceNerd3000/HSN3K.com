Key Capabilities

FEATURES

Designed to provide a easy and reliable countdown manager for Rocket Launch Streams

[01] Countdown Manager

In-built manager of countdown UI with auto-hold, scrub, and pausing capabilities.

[02] GO-NOGO Displays

In-built system to display GO-NOGO stats, with adaquite colors for different status'.

[03] Major Concerns Display

In-built system to display major concerns in a bullet-list format.

[04] Spreadsheet Integration

Integration with spreadsheet using google sheets, or manual data entry.

[05] Customization

Color of various UI elements can be customized. There are current plans for more customization, but this is down the line.

[06] Much More!

More features are planned, and will come out over time.

Developer & Source Build

SOURCE

If you prefer running Downlink from source on Linux or modifying the UI, you can clone the repository and run it directly in a Python environment.

# Clone repository
git clone https://github.com/HamsterSpaceNerd3000/RocketLaunchCountdown
cd downlink

# Set up virtual environment and run
uv venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
